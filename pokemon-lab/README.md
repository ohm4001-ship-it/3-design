# POKÉ LAB

브라우저에서 나만의 포켓몬풍 3D 캐릭터를 만들고, 그 친구와 함께 섬을 탐험하며 야생 포켓몬을 수집하고 던전에 도전하는 싱글 플레이 게임입니다. 별도 서버나 계정 없이 실행되며, Three.js로 캐릭터·오픈월드·던전을 직접 생성합니다.

## 실행

Node.js 20 이상과 npm이 필요합니다. 이 폴더에서 실행하세요.

Windows에서는 `start.cmd`를 더블클릭해 실행할 수도 있습니다. 개발 서버가 실행되고 브라우저가 열립니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 주소를 엽니다. 기본 주소는 `http://127.0.0.1:5173`이며, 사용 중이면 다른 포트가 표시됩니다. WebGL을 지원하는 최신 Chrome 또는 Edge를 권장합니다.

```bash
npm test          # 설정·저장 복구·포획·탐험 보상 규칙 테스트
npm run build    # dist/에 배포용 정적 파일 생성
npm run preview  # 빌드 결과 로컬 확인
```

`index.html`을 직접 더블클릭하는 대신 개발 서버 또는 정적 웹 서버로 실행해야 합니다.

## 섬 탐험하기

첫 화면은 **탐험**입니다. 햇살 초원에서 출발해 속삭임 숲, 별빛 호수, 달빛 유적을 자유롭게 걸어 다닐 수 있습니다. 작은 친구에게 가까이 다가가면 상호작용 버튼이 나타납니다.

- 지역마다 배치된 16마리의 야생 포켓몬과 연구소에서 직접 만들고 **컬렉션에 저장한 포켓몬**을 만날 수 있습니다. 제작 포켓몬은 최대 24마리까지 섬에 추가되며, 저장된 캐릭터 ID를 기준으로 출현 위치가 유지됩니다.
- 가까운 포켓몬에게 말을 걸어 포획 미니게임을 시작하세요. 바늘이 초록 구간에 들어올 때 볼을 던지면 도감에 등록됩니다. **천천히 친해지기** 버튼은 타이밍 입력 없이 같은 포획 결과를 제공하므로 움직이는 바늘을 따라가기 어려워도 수집할 수 있습니다.
- 포획 성공 시에만 몬스터볼 1개를 사용하고 경험치 35를 얻습니다. 실패한 시도에는 볼을 사용하지 않습니다. 같은 개체의 포획이나 보상은 중복 처리되지 않습니다.
- 반짝 열매는 한 번씩 수집할 수 있으며 몬스터볼 3개와 경험치 10을 줍니다. 명소 첫 방문은 볼 4개와 경험치 30을 줍니다. **새싹 캠프에서 휴식하면 볼이 최소 12개로 보충**되어 볼을 모두 사용해도 탐험을 이어갈 수 있습니다.
- 미니맵과 전체 지도에서 위치를 확인하고, 발견한 명소로 빠르게 이동하세요. 캠프는 처음부터 빠른 이동을 사용할 수 있습니다.
- 포켓몬 수집, 지역 탐험, 명소 발견으로 네 가지 탐험 목표를 완료할 수 있습니다. 경험치를 모으면 탐험 레벨이 오릅니다.
- 연구소의 초안·저장한 캐릭터·포획한 포켓몬 중에서 동행 파트너를 선택할 수 있습니다. 도감의 친구를 연구소로 보내 다시 꾸밀 수도 있습니다.

### 조작

| 입력 | 동작 |
| --- | --- |
| W / A / S / D 또는 방향키 | 이동 |
| Shift | 누르는 동안 달리기 |
| Space | 점프; 포획 화면에서는 볼 던지기 |
| E | 가까운 포켓몬·열매·명소와 상호작용 |
| M | 전체 지도 열기 |
| B | 탐험 도감 열기 |
| Esc | 열린 창 닫기; 확대 화면 종료; 탐험 화면에서 일시 정지·재개 |
| 화면 드래그 / 휠 | 시점 회전 / 거리 조절 |

터치 화면에서는 방향 패드를 누르고 이동하며, 달리기 버튼으로 달리기를 켜고 끕니다. 점프·상호작용·지도·도감 버튼도 화면에서 사용할 수 있습니다. 창을 열거나 다른 탭으로 전환하면 탐험 움직임이 멈춥니다.

## 던전 원정

탐험 화면의 **던전 원정**에서 현재 파트너와 함께 출발합니다. 섬의 달의 제단에서도 원정을 시작할 수 있습니다. 이끼빛 성소(입문), 잿불 공방(보통), 달그림자 유적(도전) 중 하나를 선택하세요. 각 던전에는 연결된 세 방과 마지막 방의 수호자가 있습니다.

1. 공간을 이동해 파수꾼에게 가까이 다가간 뒤 **E** 또는 도전 버튼으로 전투를 시작합니다.
2. 전투는 턴 방식입니다. **다음 공격 예고**를 확인하고 기본 공격, 속성 기술, 방어, 회복약 중 하나를 선택하세요. 버튼을 누르기 전에는 적이 공격하지 않습니다.
3. 기본 공격과 방어는 에너지를 1 회복하고, 속성 기술은 에너지를 2 사용합니다. 방어는 이번 턴 받는 피해를 75% 줄입니다. 회복약은 원정마다 2개이며 체력을 최대 40 회복합니다.
4. 첫째·둘째 방을 통과하면 공격, 체력, 피해 감소 중 **축복 하나**를 선택합니다. 같은 축복을 중복으로 선택할 수 없으며, 축복은 현재 원정에만 적용됩니다. 열린 문으로 이동해 다음 방에 진입하세요.
5. 마지막 수호자를 이기면 던전을 완료합니다. **던전별 최초 완료에만** 수호자 친구와 경험치, 볼 6개를 받습니다. 수호자는 탐험 도감에 등록되어 파트너로 선택하거나 연구소에서 꾸밀 수 있습니다. 완료한 던전에 다시 도전할 수 있지만 최초 보상은 반복 지급되지 않습니다.

### 던전 조작

| 입력 | 동작 |
| --- | --- |
| W / A / S / D 또는 방향키 | 던전 이동 |
| Shift / Space | 달리기 / 점프 |
| E | 가까운 적과 전투 시작; 열린 문으로 다음 방 이동 |
| J / K | 기본 공격 / 속성 기술 |
| L / H | 방어 / 회복약 사용 |
| Esc | 원정 일시 정지·재개 |

이동·상호작용·전투는 화면 버튼으로도 가능합니다. 터치 화면에는 이동 패드가 표시됩니다. 전투 중 이동은 멈추며, 키를 길게 눌러도 행동을 연속 소비하지 않습니다. 섬 조작은 이전과 같습니다.

**진행 중인 원정은 저장하지 않습니다.** 새로고침하거나 상단의 **만들기·컬렉션 화면으로 이동하면** 현재 원정이 끝납니다. 탐험 화면으로 돌아올 때는 섬에서 다시 시작합니다. 쓰러지거나 중도 귀환해도 기존 컬렉션, 도감, 섬 진행과 소지품은 잃지 않습니다. 원정의 체력·에너지·회복약은 다음 출발 시 초기화됩니다. 다른 브라우저 탭에서 탐험 저장이 바뀌면 현재 원정을 종료하고 최신 기록을 불러옵니다.

최초 완료 기록과 수호자 보상은 기존 탐험 저장에 함께 기록됩니다. 도감이 가득 차면 최초 보상을 소비하지 않고 정원 초과를 안내합니다.

### 게임 레퍼런스

공식 소개에서 확인한 구조를 이 프로젝트의 규모에 맞게 적용했습니다. 원작의 이미지·3D 모델·맵·음원은 사용하지 않습니다.

- [포켓몬 불가사의 던전 구조대 DX](https://mysterydungeon.pokemon.com/en-us/world/): 파트너와 던전 임무를 수행하고 새로운 친구를 동료로 맞이하는 흐름.
- [Minecraft Dungeons](https://www.minecraft.net/en-us/about-dungeons): 전투, 보물, 마지막 목표로 이어지는 짧은 던전 탐험 동선.
- [Hades 개발자 패치 노트](https://www.supergiantgames.com/blog/hades-welcome-to-hell-update-patch-notes/): 원정 중 강화 선택과 다음 방 보상 미리보기. 이 프로젝트는 실시간 전투 대신 턴 방식과 세 방 구성을 사용합니다.

설계 결정과 완료 기준은 [던전 원정 설계 기록](docs/designs/dungeon-expeditions.md)에 정리했습니다.

## 만들 수 있는 것

- 피카츄·이상해씨·꼬부기·파이리·이브이·팬텀에서 영감을 받은 6가지 시작 프리셋
- 이름, 6가지 속성, 8가지 색상 팔레트와 사용자 색상 설정
- 몸체·귀·꼬리·표정·액세서리 조합, 몸체 및 귀 크기 조절
- 실시간 3D 회전·확대·자동 회전, 배경 변경과 시점 초기화
- 랜덤 생성, 실행 취소, 초안 자동 저장, 최대 24개 컬렉션 저장 및 재편집
- PNG 이미지, GLB 3D 모델, 편집 가능한 `.pokelab.json` 프로젝트 내보내기
- 프로젝트 JSON 다시 불러오기: 이 앱의 버전 1 형식, 최대 2MB
- 모바일 화면 대응, 키보드 탭 탐색, 동작 줄이기 설정 반영

## 저장 방식

초안, 컬렉션, 탐험 진행은 **현재 브라우저의 localStorage에만 저장**됩니다. 로그인·클라우드 동기화·공유 서버는 없습니다. 다른 기기나 브라우저에는 자동으로 전달되지 않으며, 브라우저 데이터를 지우면 저장 내용도 사라집니다. 호스트나 포트가 바뀌면 별도 저장 공간을 사용합니다.

탐험 진행은 연구소 데이터와 분리된 `pokemon-lab.world.v1` 키에 자동 저장됩니다. 위치, 발견한 지역, 포획한 포켓몬, 경험치, 남은 볼, 수집한 열매, 방문한 명소, 선택한 파트너와 던전 최초 완료 기록을 복원합니다. 초안은 `pokemon-lab.draft.v1`, 제작 컬렉션은 `pokemon-lab.collection.v1` 키를 사용합니다. 도감에는 최대 128개의 포획 기록을 보관합니다.

컬렉션은 최대 24개이며 브라우저 저장 용량에 따라서 더 일찍 저장이 실패할 수 있습니다. 오래 보관할 작업은 프로젝트 JSON으로 내려받으세요. GLB는 다른 3D 도구에서 사용하기 위한 결과물이며, 이 앱에서 다시 편집하려면 JSON 파일을 사용합니다.

프로젝트 JSON 내보내기는 캐릭터 설정을 저장합니다. 전체 탐험 진행을 백업하거나 다른 기기로 옮기는 기능은 포함하지 않습니다.

## 게임 범위

하나의 섬과 세 테마의 던전에서 탐험·수집·턴 전투를 즐기는 브라우저 프로토타입입니다. 멀티플레이, 계정, 서버 저장, 실시간 액션 전투, 교환, 절차적 무한 월드는 포함하지 않습니다. 야생 개체와 열매는 정해진 위치에 등장하며, 포획하거나 수집한 개체는 같은 저장 기록에서 다시 생성되지 않습니다. 던전은 미리 설계한 세 방 구성입니다. 포켓몬 생성 기능과 PNG·GLB·프로젝트 파일 내보내기는 기존 연구소에서 계속 사용할 수 있습니다.

## 구성

```text
index.html          화면 구조
src/main.js         편집기·컬렉션·파일 내보내기/불러오기
src/scene.js        Three.js 모델 생성·조명·카메라·GLB 내보내기
src/data.js         프리셋·설정 검증·브라우저 저장
src/style.css       반응형 디자인
src/world-ui.js     탐험 HUD·지도·도감·포획·연구소 연결
src/world-scene.js  섬 지형·장식·이동·카메라·야생 포켓몬
src/world-data.js   지역·출현 위치·포획·보상·탐험 저장 규칙
src/world.css       탐험 화면·모바일 조작·대화상자 디자인
src/dungeon-ui.js   던전 로비·전투·축복·원정 결과·입력 처리
src/dungeon-scene.js 던전 공간·파트너·적·문·이동·카메라
src/dungeon-data.js 던전 테마·적·턴 전투·축복·진행 규칙
src/dungeon.css     원정 로비·던전 HUD·반응형 전투 화면
tests/data.test.js  데이터 및 저장 로직 테스트
tests/world-data.test.js 탐험 규칙·저장 복구·중복 보상 방지 테스트
tests/dungeon-data.test.js 던전 진행·전투·강화·보상 규칙 테스트
```

Vite, Three.js, Lucide 아이콘을 사용합니다. 모델·장식 이미지는 코드에서 직접 만든 포켓몬풍 창작 에셋이며, 원작의 공식 3D 모델을 가져오거나 정확히 복제한 에셋이 아닙니다. Pokémon과 연관된 공식 서비스가 아닌 팬 창작 프로젝트입니다.
