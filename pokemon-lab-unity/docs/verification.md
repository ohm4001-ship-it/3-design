## 브라우저 검증

- 섬·공방 화면, 키보드 이름 입력과 한국어 붙여넣기, 저장 후 새로고침으로 복원되는 진행 확인.
- 달그림자 유적 진입 후 속성 기술 29 피해 확인. 행동 후 파트너 HP 88, 적 HP 25/54로 전투 상태 갱신.
- `Downloads/friend.pokelab.json` 실제 다운로드 확인. `format: "poke-lab"`, `version: 1`, 이름 `민트모찌` 검사.
- JSON 붙여넣기로 `별빛모찌` 불러오기 확인. 보라색·긴 귀·꽃 장식·고스트 속성 적용 후 저장 버튼 실행.
- 최종 빌드 검증 구간인 **05:44 UTC 이후** 브라우저 콘솔에 새 경고·오류가 나타나지 않음.

## 증거와 범위

프로젝트의 `Evidence/runtime/`에 `01-world.png`부터 `11-moon.png`까지 11개 네이티브 화면과 `runtime-smoke.txt`를 보관했다. `Evidence/web-creator.jpg`는 최종 브라우저 공방 화면이며, `Evidence/geometry-validation.txt`는 생성 지오메트리 결과다. Windows 실행 시 원본 캡처는 `Builds/Windows/Evidence/`에 기록된다.

Unity Editor 첫 검색 인덱싱에서 Unity Search 내부 예외가 관찰되었으므로 Editor 로그 전체가 오류 없이 끝났다고 기록하지 않는다. 프로젝트 컴파일·Windows 빌드·네이티브 스모크·최종 브라우저 검증의 결과는 위와 같이 각각 확인했다. 모바일·다른 브라우저·외부 호스팅 환경은 이번 검증 범위에 포함하지 않는다.
