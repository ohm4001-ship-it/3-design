## Edge Cases

  Value: protects=finite safe projection results; fails_when=invalid depth is sampled as foreground; why_new=canonical fixtures do not cross a perspective plane; seam=none; no_claim=fitting quality
- E2 [P8/P10]: One inconsistent photo, all contradictory photos or insufficient directions produce manual review/initial-only/explicit error rather than normal completion.
  Value: protects=valid shape under unreliable observations; fails_when=all masks are intersected without confidence checks; why_new=reference mismatch tests cannot cover photo support; seam=none; no_claim=automatic recovery from every bad photo
- E3 [P9/P10]: Missing, cancelled or unidentifiable required protection blocks deformation; failed connection, thickness or hole checks restore prior valid mesh.
  Value: protects=confirmed protection and rollback; fails_when=component count substitutes for hole visibility; why_new=existing shrinkwrap test has no selected regions; seam=none; no_claim=initial geometry is physically correct
- E4 [P11/P20]: Read legacy reference state; reject invalid photo calibration or fabricated confirmed flags; crop/reupload/swap/mesh replacement invalidates dependent fits, anchors and measurements. A pending record with old identity cannot attach to the replacement geometry or photograph.
  Value: protects=state identity and migration; fails_when=bad pose silently becomes identity camera; why_new=current orientation has quarter-turn defaults only; seam=none; no_claim=all historical state variants
- E5 [P13/P17/P19/P20]: Rapid repeat, navigation/reload pending request, network loss, malformed response/payload, bad asset status/parse and server error remain recoverable; no stale success indication. Under D15 A, state refresh retains relevant logical task/control focus; removed controls fall back to the labeled task heading, typing is not interrupted, and confirmed-step progression remains intact. Slow model A arriving after model B or after viewer disposal cannot change active identity/task or leak attached resources; the next valid request still succeeds.
  Value: protects=ordered recovery, task focus and active viewer ownership; fails_when=late load wins or redraw loses the current task; why_new=current tests lack UI and viewer lifecycle coverage; seam=none; no_claim=distributed concurrency or measured latency
- E6 [P14]: Zero-length spans, zero/negative/nonfinite measurements and incompatible multiple spans report the issue without hidden axis stretch.
  Value: protects=valid dimension constraints and residuals; fails_when=invalid input scales or distorts the mesh; why_new=measurement feature has no current coverage; seam=none; no_claim=real-world measurement precision
- E7 [P16]: Unsupported single-photo inference, checkpoint/GPU failure and absence of an initial mesh produce explicit cause and recovery choices; uncertain photo cameras prohibit automatic hull fallback.
  Value: protects=guarded provider failure handling; fails_when=AI error silently runs unsafe photo hull; why_new=existing AI fallback proves reference mode only; seam=none; no_claim=provider availability or successful inference
